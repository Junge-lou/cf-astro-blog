**状态**：待执行
**决策来源**：方向 A（物理基底 = 米白棉纸 + 钴蓝墨）、头像移入肖像位、Hero 大数字 = 文章总数
**范围**：整站框架重写，不兼容现有玻璃风格

## 0. 设计规范（先定死，后面所有实现都以这张表为准）

### 0.1 色板：纸 + 墨 + 一枚金

钞票是「一种纸 + 一种主墨 + 一处光变金属」，不是调色板。因此颜色收敛到三组。

| Token | 值 | 说明 |
| --- | --- | --- |
| `--paper-100` | `#f4f1e6` | 票面纸基（页面底色） |
| `--paper-200` | `#ebe6d6` | 纸的暗面（凹槽、页脚） |
| `--paper-300` | `#ded7c2` | 纸的折痕/分隔线 |
| `--sheet-100` | `#faf8f0` | 卡片"纸片"（比底色略亮） |
| `--ink-900` | `#12243a` | 主墨（正文）。不用纯黑：流通钞票的墨是蓝黑 |
| `--ink-700` | `#2c3d55` | 次级文字 |
| `--ink-500` | `#5a6a80` | 辅助文字（日期、标签） |
| `--cobalt-600` | `#0047ab` | 主墨蓝（品牌色，保留） |
| `--cobalt-800` | `#00306e` | 深墨蓝（边框、悬停） |
| `--gold-500` | `#9a7b32` | **仅装饰**：印章、序号分隔点。禁止用作正文或小字 |

> `--gold-500` 对 `--paper-100` 的对比度约 3.1:1，**不满足 AA 正文要求**，因此它只能出现在纯装饰元素上（`aria-hidden`）。

### 0.2 几何：直角化

钞票没有圆角。这是本次最直观的观感切换。

| Token | 旧值 | 新值 |
| --- | --- | --- |
| `--radius-sm` | 10px | `1px` |
| `--radius` | 14px | `2px` |
| `--radius-lg` / `-card` | 18px | `3px` |
| `--radius-xl` / `-panel` | 24px | `4px` |
| `--radius-pill` | 999px | 保留（仅用于标签胶囊，钞票上的序号牌也是椭圆形） |

### 0.3 边框：双线 = 票面安全区

所有面板统一为「外线 + 内线」双层，代替旧的玻璃描边：

```css
.paper-sheet {
 border: 1px solid rgb(0 48 110 / 0.28);          /* 外线 */
 box-shadow: inset 0 0 0 3px var(--paper-100),     /* 纸缝 */
             inset 0 0 0 4px rgb(0 48 110 / 0.16); /* 内线 */
}
```

四角加粗（`::before` 绘制 4 个 L 形角标，1.5px），模拟票面四角。

### 0.4 排版：沿用黄金刻度，新增两个角色

字号刻度（7 档 √φ）**不改**。新增：

| 角色 | 字体 | 用途 |
| --- | --- | --- |
| `--font-serial` | `var(--font-mono)` + `font-variant-numeric: tabular-nums` | 序列号、日期、字数、计数 |
| 微缩文字 | `--text-sm` × 0.55（约 7px）+ `letter-spacing: 0.28em` | 页脚纹理行、卡片底线 |

### 0.5 五个标志性元素

| 元素 | 组件 | 出现位置 |
| --- | --- | --- |
| 票面边框 | `BanknoteFrame.astro` | Hero、卡片、页脚、文章正文 |
| 序列号 | `Serial.astro` | 每篇文章（`№ 000042`）、归档列表序号列 |
| 面额徽记 | `Denomination.astro` | Hero（文章总数，巨型）、卡片角标（序号） |
| 肖像位 | Hero 内头像 | 首页唯一一处 |
| 微缩行 | `MicroPrint.astro` | 页脚 |

### 0.6 明确不做（防止变成 cosplay）

- ~~不铺满屏的扭索纹（guilloché）—— 覆盖率必须 < 10%，只用于边框内衬~~
  → **已作废（票面改版后）**。扭索纹现在是铺满全票的纸纹，实测覆盖约 61%。
  现行约束改为：扭索纹不透明度不得高于 0.35，且不得把任何文字区块的对比度压下去。
- 不做光变油墨动画
- ~~不复用任何真实钞票图案/字体（美国财政部对货币图像复制有规定）~~
  → **2026-10-29 站长决定破例**。首页票面改用自绘的货币元素：
  富兰克林肖像、美联储徽记、整票边框、真实签名、羽毛笔。
  破例边界（仅首页票面组件、不扩散到其他页面、不自称是真实货币）
  与实施细节见 `docs/bill-image-components-plan.md`。
- 正文永远左对齐，不做居中对齐的长文

## 2. 执行计划

### Phase 0 —— 并行侦察（已完成）

三个只读子 agent 并行跑完，结果如下（这些数字决定了后面的取舍）：

| 项 | 实测 |
| --- | --- |
| `backdrop-filter` 声明 | **58 处**（30 标准 + 27 webkit + 1 在 `transition` 列表里） |
| `--glass-*` 变量出现 | **97 处 / 10 个变量** |
| `--card-surface-rgb` 等 rgb 变量 | **190 处** |
| `glass-panel` 标记引用 | 20 处（18 元素 + 2 个动态 class 数组） |
| 软阴影 / 玻璃高光渐变 | 28 + 17 处 |
| **去重后待改点** | **≈342 个 `file:line`，20 个文件** |
| 测试 | 34 文件 / 279 例，其中 **11 个文件含视觉断言**，`header-motion.test.ts` 需整篇重写 |

**策略修正（重要）**：原计划打算 Phase 1 就引入 `.paper-sheet` 并全面替换类名。但 342 个点分属 20 个文件，若中途停下，站点会处于"一半纸片一半玻璃"的破碎状态。

改为：**Phase 1 只换"皮"不换"钩子"** —— 把 `.glass-panel` 的**样式**改成纸片，但**保留类名**；Phase 3 逐文件把类名切成 `.paper-sheet`；Phase 5 再删掉 legacy 别名。这样任何中间态都是可渲染、可回滚的。

另外侦察发现两个既有问题（不在本次范围，记录备查）：

- `0001` 建表时 `background_blur` 默认 24、`0015` 的 `background_opacity` 默认 72，与 `schema.ts` 的 0 / 50 不一致
- 「首页卡片透明度」滑块**实际不影响首页 Hero**（Hero 只接了 blur，没接 opacity），它改的是导航栏/页脚/归档/搜索/友链/404

## 3. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 直角 + 纸色在中文长文上显"旧" | Phase 3 后立刻出截图对比；若不满意只回退 §0.2 圆角，色板不动 |
| 后台外观滑块语义变化让站长困惑 | Phase 4 在后台每个滑块旁加一行说明文字 |
| 现有 279 个测试大量依赖视觉断言 | Phase 0/A2 先出清单，一次性改完，不边改边猜 |
| 移除 `backdrop-filter` 后某些层级失去分隔 | 用双线边框 + 纸影替代，验收时逐页检查 |

**回滚方式**：本次改造集中在 `global.css` + 组件，`git revert` 单个 commit 即可整体回到玻璃风格。建议**分 3 个 commit**：Phase 1、Phase 2-3、Phase 4-5。
