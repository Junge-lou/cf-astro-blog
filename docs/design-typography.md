# 字号刻度（黄金比例）

全站只有 **7 档**字号，定义在 `src/styles/global.css` 的 `:root`。任何 `font-size`
都必须引用这些变量，不再写死数值。

## 为什么是 √φ 而不是 φ

黄金比例 φ = 1.6180339887。如果直接用 φ 当级差，从正文 16px 往上一步就是 25.9px：

```
16 → 25.9 → 41.9 → 67.8 → 109.7 …
```

7 档只能覆盖 25.9–186px，而 UI 里真正密集的 12–16px 区间一档都没有。

所以**级差取半阶 √φ ≈ 1.272**。好处是黄金比例的自相似性完全保留：

| 跨度 | 倍数 |
| --- | --- |
| 1 档 | √φ ≈ 1.272 |
| 2 档 | φ = 1.618 |
| 4 档 | φ² = 2.618 |

相邻两档的比值恒定，而"隔两档正好是 φ"这条性质让任何一次跨级搭配都天然有黄金比例关系。

## 七档刻度

`1rem = 16px`（继承浏览器默认字号，用户改字号时整套等比缩放）。

| Token | 倍数 | rem | px | 用途 |
| --- | --- | --- | --- | --- |
| `--text-sm` | 1/√φ | 0.7862 | **12.58** | 日期、标签、kbd、辅助说明 |
| `--text-md` | 1 | 1 | **16.00** | **正文基准**（导航、正文、表格） |
| `--text-lg` | √φ | 1.272 | **20.35** | 引导段（`.page-intro`）、正文 h4 |
| `--text-xl` | φ | 1.618 | **25.89** | 大卡标题、正文 h3 |
| `--text-2xl` | φ√φ | 2.0582 | **32.93** | 区块标题（h2） |
| `--text-3xl` | φ² | 2.618 | **41.89** | 页面标题（列表页 h1） |
| `--text-4xl` | φ²√φ | 3.3302 | **53.28** | Hero 标题、文章标题 |

后三档是流体值，**上下界都落在刻度上**：

```css
--text-2xl: clamp(1.618rem, 1.15rem + 1.6vw, 2.0582rem);  /* 25.89 → 32.93 */
--text-3xl: clamp(2.0582rem, 1.3rem + 2.1vw, 2.618rem);   /* 32.93 → 41.89 */
--text-4xl: clamp(2.0582rem, 1.55rem + 3.4vw, 3.3302rem); /* 32.93 → 53.28 */
```

小屏时字号"提前停在下界"，不会掉出刻度，因此移动端不需要另造一套字号表。

实测（`getComputedStyle`）：

| 位置 | 1440px | 390px |
| --- | --- | --- |
| 首页 h1 | 53.28px | 38.06px |
| 文章标题 | 53.28px | — |
| 区块标题 h2 | 32.93px | 25.89px |
| 正文 | 16px | 16px |
| 标签胶囊 | 12.58px | 12.58px |

## 已知取舍：最小屏会合并相邻档

`--text-2xl` 的下界就是 `--text-xl`，所以在 390px 这类窄屏上，"区块标题"和"大卡标题"
会都停在 25.89px。这是 7 档刻度在移动端的固有限制——要彻底分开必须增加档位，
那会破坏"7 档"这个约束。目前靠字重与字体族（块标题无衬线加粗、卡标题衬线）区分层级。

## 例外（仅两类，测试已放行）

1. **`html` 上的 `1rem`** —— 刻度本身的锚点，也是 `rem` 的参照物，不能写成变量
   （会形成循环依赖）。
2. **`em`** —— 行内 `code`、`sup`/`sub`、聊天气泡等必须跟随父级字号。
3. **410 页面**（`src/pages/blog/[slug].astro`）是完全自包含的 HTML 文档，在 Worker 里
   直接返回、不经过 Base 布局，拿不到 CSS 变量，内联字号只能写字面量。

## 测试闸门

`tests/unit/type-scale.test.ts` 会阻止刻度退化：

1. `global.css` 必须正好定义这 7 个 token；
2. 固定档位必须严格按 √φ 递进（隔 2 档 = φ、隔 4 档 = φ²）；
3. 流体档位的上下界必须落在刻度上；
4. 源码里不允许出现裸字号（`em` 与上述两个例外除外）。

新增组件时写 `font-size: var(--text-md)`，不要再写 `font-size: 0.95rem`。
